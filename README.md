# Muddasir Amjad — Portfolio

Interactive portfolio built with Next.js, Tailwind CSS and Framer Motion. Features a 3D hero, tilting project mockups and a light/dark theme.

## Run locally

```bash
npm install
npm run dev
```

Requires Node.js 20.9 or newer. Open http://localhost:3000.

## Deploy

Import the repository on [Vercel](https://vercel.com/new); no environment variables are needed.
